# User Stories

**Status:** Draft for founder approval

## Tenant and access

- As a business owner, I want to register my business so that I can operate
  an isolated workspace.
- As a business owner, I want to invite staff and technicians so that work can
  be shared safely.
- As a user, I want permissions limited to my tenant and branch scope so that
  private business data is protected.

## Customer and inquiry management

- As a dispatcher, I want to create or find a customer while recording an
  inquiry so that I do not lose requests received through existing channels.
- As a dispatcher, I want to record contact details, service address, AC
  details, preferred date, source channel, and notes so that the team has
  complete context.
- As a dispatcher, I want to track inquiry status and follow-up activity so
  that forgotten inquiries are visible.
- As a dispatcher, I want to convert an approved inquiry into a booking and job
  order so that information is not re-entered.

## Booking and quotation

- As a dispatcher, I want to view technician availability so that I avoid
  double bookings.
- As a dispatcher, I want to create either a standard-price booking or a
  quotation so that variable AC-cleaning requests are supported.
- As a customer, I want to review and approve a quotation through an existing
  channel or secure link so that my approval is recorded.

## Technician workflow

- As a technician, I want to see my assigned jobs and schedules on my phone so
  that I know where to go and what work is expected.
- As a technician, I want to update Assigned, In Progress, and Work Completed
  statuses so that the office can monitor progress.
- As a technician, I want to add notes, photos, materials, and additional
  findings so that the work is documented.
- As an owner or dispatcher, I want to review and request corrections so that
  only verified work proceeds to invoicing.

## Billing

- As authorized staff, I want to create an invoice from the job so that
  charges are recorded consistently.
- As authorized staff, I want to record cash, GCash, or bank-transfer payments
  with references and proof so that payment history is reliable.
- As an owner, I want unpaid, partially paid, and fully paid statuses so that I
  can monitor outstanding balances.

## Reporting and customer access

- As an owner, I want basic job, inquiry, revenue, and outstanding-balance
  reports so that I can monitor operations.
- As staff, I want to issue a secure, time-limited customer link so that a
  customer can view only their permitted information without an account.
