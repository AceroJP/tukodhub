# Decision 0014: First Service-Type Priority

**Date:** 2026-11-10  
**Phase:** Phase 0 - Product Discovery  
**Status:** Founder decision; pending workflow validation

## Decision

## Scope implication

Preventive maintenance, repair and troubleshooting, and installation remain
possible supported services, but they are not the first workflow to optimize.
