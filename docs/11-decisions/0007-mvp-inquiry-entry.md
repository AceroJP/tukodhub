# Decision 0007: MVP Inquiry Entry

**Date:** 2026-11-10  
**Phase:** Phase 0 - Product Discovery  
**Status:** Direction chosen; launch priority unresolved

## Decision

The MVP should support both staff-entered inquiries from existing channels and
customer-submitted requests through a public booking page.

## Rationale

Staff entry supports the current behavior of receiving inquiries through
Messenger, phone, and SMS. A public booking page could provide a direct,
structured request path for customers.

## Unresolved issue

The first launch path must still be prioritized. Supporting both paths may
increase onboarding, customer-adoption, and support complexity. Interviews
should test whether businesses will actively promote or use a public booking
page, or whether staff entry is the more valuable first workflow.
