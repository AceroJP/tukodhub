# Decision 0008: Launch-Critical Inquiry Path

**Date:** 2026-11-10  
**Phase:** Phase 0 - Product Discovery  
**Status:** Founder decision; pending workflow validation

## Decision

Staff-entered inquiries from Facebook Messenger, phone calls, SMS, and
walk-ins are the launch-critical MVP path. The public customer booking page is
secondary and must not delay the initial MVP release.

## Required staff workflow

Staff must be able to:

- Create or find customer records.
- Record a new service inquiry.
- Select the requested service.
- Capture customer contact information and service address.
- Set a preferred appointment date.
- Track inquiry status.
- Convert an approved inquiry into a booking and job order.

## Rationale

The target businesses already communicate with customers through these
channels. The initial product should organize existing operations without
requiring an immediate change in customer communication habits.

## Validation note

The workflow and priority are founder decisions for the current hypothesis.
Interviews must verify that this workflow is common and that it addresses the
highest-value operational problem.
